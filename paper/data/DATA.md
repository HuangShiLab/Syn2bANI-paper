# Data Index

This directory documents the datasets used in the current manuscript. Raw inputs and per-pair outputs are stored under `data/` and `results/` in the repository root.

## Simulation Data

Exact-truth simulations used to validate the raw estimator and robustness:

- ANI ladder (85–99.9% true ANI) with counted substitutions on *E. coli* K-12 MG1655
- Indel family: fixed 95% core ANI with 0–4 deletions per 100 kb
- Fragmentation family: 20–201 contigs, shuffled/oriented
- GC family: five template genomes spanning 27.2–72.1% GC
- Accessory-content family: 0–50% shuffled non-homologous blocks
- Mosaic family: core + divergent region mixtures

Simulation inputs and truth labels are generated by the Syn2bANI prototype harness.
See `paper/data/SIMULATION_AND_PERFORMANCE_REPORT.md` for the full simulation and performance-benchmark record.
