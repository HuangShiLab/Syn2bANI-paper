# Syn2bANI — Simulation and Performance Validation Report

Internal technical documentation supporting the manuscript. Scope: the
simulation strategy and its known blind spots, accuracy against exact and
reference-tool truth, enzyme-panel selection, and computational efficiency.
Every number below is traceable to a file; sources are given in parentheses.
Figures live in `../figures/report/` and are generated by
`analysis/plot_report_figures.py`.

Tool under test: syn2bani 0.1.0, Syn2bANI main @ `69ce9f4`, default enzyme
panel **BcgI,AlfI,AloI,FalI** (the GTDB-R207 embedded calibration model was
trained on this panel's feature distribution). Comparators: skani 0.1.0,
FastANI 1.33/1.34, ANIm (dnadiff 1-to-1) as alignment truth.

## 2. Simulation strategy

The simulations are half the argument of this report: they provide *exact*
ground truth, which no reference-tool comparison can. This section documents
what each family does, what the paradigm deliberately omits, and where it has
already failed to predict real-data behavior.

### 2.1 Core design principle: exact truth by construction

All simulators evolve sequence from one reference — *E. coli* K-12 MG1655
(ENA `U00096.3`) for most families — by applying a **counted** number of
substitutions, so true ANI = 1 − n_subs / L exactly, regardless of how the
substitutions are distributed (`prototype/simulate.py`). Enzyme digestion is
never simulated: the Rust tool itself extracts tags from the evolved FASTA,
so the full digest → chain → likelihood path is exercised end to end. Each
family writes a manifest carrying the truth; evaluators never re-derive it.

### 2.2 Simulation families and parameter grids

| Family | Script | Grid | What it isolates |
|---|---|---|---|
| ANI ladder | `simulate.py` | 12 levels, true ANI 0.85→0.999, each with a 400 kb inversion | accuracy vs divergence; chaining across an orientation flip |
| Ladder + indels | `simulate.py <indel_rate>` | same 12 levels + ~46 deletions of 200–2000 bp | gap arithmetic inside chains |
| Indel sweep | `simulate_indel_sweep.py` | true ANI fixed 95.000; 0, 0.5, 1, 2, 4 deletions/100 kb (0→4.3% of genome) | error drift vs indel load |
| Fragmentation | `fragment.py` | 20/50/100/200 target contigs (no sequence lost), ~50% of contigs reverse-complemented, order shuffled | fragmentation artifact; strand-canonical hashing |
| Accessory confound | `simulate_accessory.py` | core ANI fixed 95.000; 0–50% of genome replaced by shuffled (composition-preserving, homology-destroying) blocks | divergence vs shared-content confound |
| Mosaic / rate heterogeneity | `simulate_mosaic.py` | per-block rates ~ Gamma(α,α), α = 0.5/1/2, mean ANI 90–98; plus bimodal 50/70%-core misspecification cases | the gamma model against (mis)specified truth |
| GC coverage | `gc_bench.py` | ladders simulated on 5 real template genomes, GC 27.2–72.1% | genome-composition effects under exact truth |

Design details that matter:

- **Inversions** (400 kb, reverse-complemented in place) force collinear
  chaining across an orientation flip on every ladder genome.
- **Deletions do not change true ANI** (truth is counted substitutions over
  the reference length); they reduce the shared fraction, so the deleted
  fraction doubles as AF ground truth.
- **Accessory blocks are shuffled real sequence**, not random DNA: base
  composition is preserved, so enzyme sites occur at the normal rate and the
  accessory region produces its own (unmatchable) tags, as real accessory
  genes do. Blocks are evenly spaced, 5 per genome (§3.3 of V8 varies the
  block count at fixed total fraction as a control).
- **Fragmentation loses no sequence** (asserted in the script), so any ANI
  drift with contig count is pure artifact — an exact control. Roughly half
  the contigs are reverse-complemented and the order is shuffled, mimicking
  real draft submissions.
- **Mosaic cases** assign per-block rate multipliers, rescaled to an exact
  mean of 1, so the whole-genome truth stays exact while the spatial
  distribution varies. The `gamma` regime is precisely the model
  `estimate_heterogeneous` fits; the `bimodal` regime is deliberately *not*
  the assumed distribution (misspecification test).

### 2.3 What the simulations deliberately do NOT model

Substitutions are uniform over the 3 alternative bases, at uniform rate
across sites (except the mosaic family), with no GC-biased mutation model,
no transition/transversion ratio, no codon structure or selection, and no
site creation beyond what uniform substitution produces by chance.

Two findings justify keeping it this simple:

- **GC does not explain the real-data degradation** (ALGORITHM_MLE §4.8):
  simulating ladders on real genomes across GC 27–72% gives MAE 0.074–0.356,
  not monotone in GC, and far below the oral/gut real-data MAE of 0.552.
  A richer mutation model would not close that gap.
- **Site turnover was discovered precisely because real mutation creates new
  sites** (V8 §3.14): at 5% divergence, mutation creates +31% new BslFI
  sites whose tags score as misses. The simulator reproduces this *without*
  any special mechanism — uniform substitution on a motif-poor genome is
  enough — which is what made the mechanism measurable at all.

### 2.4 Known failure of the paradigm: fragmentation — diagnosed and fixed

Simulated fragmentation says syn2bani is robust (MAE 0.093% up to 200
contigs, V8 §3.14; F2b). Real fragmentation said otherwise: fragmenting the
real *E. coli* O157:H7 Sakai assembly drifted the estimate **+0.65 ANI points
at N50 5 kb** (V8 §3.7). The cause was structural: a chain needs
`min_chain_anchors` (4) anchors on one contig, a 5 kb contig holds ~7 tags,
and contigs that cannot form a chain were dropped from the likelihood —
selecting for well-anchored (i.e. conserved) contigs, so the miss count
eroded faster than the hit count and the estimate drifted high. Simulated
cuts cannot capture this because they preserve every base at random
boundaries, while real assemblies lose sequence at repeat boundaries and have
coverage-driven contig length distributions.

**Fix (code repo 0aabd0c): the short-contig rescue pass.** A short contig
(< 8 × `min_chain_anchors` tags) with no accepted chain but a collinear
≥ 2-unique-anchor group is folded into the likelihood without chaining: its
tags are match-tested against the reference locus the anchors point to,
counting exactly what pass-2 chaining would count on a complete genome
(chain-interior tags; tails only while a bracketing anchor follows within
`max_skip`-scaled distance). Contigs with 0–1 placeable anchors stay dropped
— the genuinely accessory fraction, which AF keeps reporting. The pass is
gated on contig tag count, so complete and high-N50 assemblies are
**bit-identical** to before. Results on the Sakai ladder: drift at N50 20 kb
+0.283 → **−0.032**, N50 10 kb +0.491 → **−0.017**, N50 5 kb +0.654 →
**+0.200** (skani −0.24, FastANI −0.64 on the same file; AF improves 0.434 →
0.580). On the 8 real ENA drafts the rc self-controls stay 99.9999 and the
worst-case bias (8,025-contig assembly) shrinks +0.91 → **+0.36** vs skani.
Full details: `results/frag_rescue/VALIDATION.md`.

The same limitation bit harder once: the CspCI 33 bp > 32-bit packing bug
(91% anchor loss on reverse strands, V8 §3.7) was **in principle**
undetectable by same-orientation simulation; only a reverse-complement
control or real drafts could see it. Both are now standard controls (§3.7).

**Status of the "robust to extreme fragmentation" claim: restored with
bounds.** The honest statement is now "drift ≤ 0.03 down to 10 kb N50 and
≤ 0.20 at 5 kb N50 — tighter than skani and FastANI on the same files — with
AF honestly reporting the unplaceable remainder." Caveat: the v4
calibration was trained on pre-rescue features; this is resolved by v5
(§3.5), retrained on post-rescue matrices with no external version skew.

## 3. Accuracy

### 3.1 Exact-truth ladder, cross-tool (F1)

![F1](../figures/report/fig1_simulation_ladder.png)

Twelve genomes at true ANI 85.0–99.9% (400 kb inversion + ~46 deletions of
200–2000 bp each; data `prototype/simindel_results_4e.tsv`,
`prototype/simindel_cross_tool_4e.tsv`).

| Method | MAE | bias | Note |
|---|---|---|---|
| syn2bani (gamma / uniform) | **0.073** | +0.073 | identical columns on this ladder |
| skani | 0.377 | −0.377 | underestimates throughout |
| FastANI | 0.742 | −0.742 | −2.05 points at true ANI 85% |

Both comparators systematically underestimate, worst at low ANI — consistent
with the ANIm-truth finding that FastANI reads 1.5–2 points low below 92%
(V8 §3.13). The no-indel ladder control scores MAE 0.053–0.074% (V8 §3.1),
so indels cost at most ~0.02. Caveats: the gamma and uniform columns are
numerically identical on all 12 rows (the LRT gate never fires on
uniform-rate data — expected, but it means this ladder cannot rank the two
estimators); the 85% level has retention 0.10 and is flagged
BELOW_DETECTION, as designed.

### 3.2 Robustness (F2)

![F2](../figures/report/fig2_robustness.png)

- **(a) Indels.** True ANI 95.000, deletions 0→4/100 kb (0→4.3% of genome):
  errors +0.032 to +0.184, MAE 0.081, **no monotone drift** (V8 §3.14).
  AF does *not* track the deleted fraction — 200–2000 bp deletions are
  bridged by gap arithmetic and remain inside chain spans, so AF measures
  chain coverage, not per-base alignment.
- **(b) Fragmentation.** 20/49/99/201 contigs, ~50% reverse-complemented,
  order shuffled: errors +0.018/+0.058/+0.116/+0.179, MAE 0.093. Random
  orientation causes no additional tag loss — the strand-canonical hashing
  fix holds under exact truth (V8 §3.14). See §2.4 for why this does **not**
  generalize to real assemblies below ~20 kb N50.
- **(c) GC.** MAE 0.074–0.356 across GC 27.2–72.1%, **not monotone in GC**;
  the worst genome (*B. longum*, GC 60.1%) sits mid-range, and MAE ≈ bias
  per genome — per-genome systematic offsets, not scatter (ALGORITHM_MLE
  §4.8). The balanced-5 panel improves 4 of 5 genomes (mean MAE
  0.179→0.153): real but modest.
- **(d) Accessory.** Core ANI fixed 95.000 with 0–50% accessory: estimate
  stays flat (+0.044 to +0.250, MAE 0.114, **not monotone in F**) while
  `af_query` tracks 1−F to within 0.004 — the two signals are decoupled
  (V8 §3.2). A residual uniform bias of ~+0.1 is **unexplained**;
  chain-boundary censoring was excluded as the cause by the block-count
  control (V8 §3.3).

### 3.3 Enzyme-panel optimization (F3) — the methodological core

![F3](../figures/report/fig3_enzyme_panel.png)

The panel is the estimator's only free design choice, and it was chosen by
measurement, not intuition.

**(a) Per-enzyme bias under uniform truth** (10 replicate genomes at exactly
95% ANI, uniform per-site divergence — no enzyme has a legitimate reason to
disagree; V8 §3.12):

| Enzyme | Bias | SD (n = 10) | Significance |
|---|---|---|---|
| AlfI | +0.273 | 0.096 | 9.0σ |
| FalI | −0.586 | 0.211 | 8.8σ |
| BcgI | +0.095 | 0.104 | 2.9σ |
| AloI | +0.011 | 0.142 | 0.2σ |

This is **reproducible systematic bias, not noise**, and it is unresolved.
Ruled out by measurement: `site_len` bookkeeping (geometry tables are
internally exact), IUPAC degeneracy (the default panel has none), tag
overlap (correlation runs the wrong way), 32-base packing (only ever
affected CspCI). The standing hypothesis is **site turnover** (below):
motifs underrepresented in the genome gain more sites by mutation than they
lose, so their tags read low; overrepresented motifs read high. That
predicts direction per enzyme from motif representation — and matches
(AlfI high, FalI low).

**(b) Panel-size trade-off** (ALGORITHM_MLE §4.7.1):

| Panel | Tags in chains | MAE real (vs skani) | MAE simulated |
|---|---|---|---|
| 4 (BcgI,AlfI,AloI,FalI) | 4,874 | **0.094** | 0.074 |
| 6 (+BplI,Bsp24I) | 6,655 | 0.167 | 0.062 |
| 8 (+PpiI,PsrI) | 7,314 | 0.141 | 0.071 |
| 8 (+CjeI,CjePI instead) | 22,141 | 0.290 | **0.038** |
| 11 (+PpiI,PsrI,HaeIV) | 120,717 | 0.670 | 0.133 |

Bigger panels help AF and simulated precision but hurt real-genome
agreement, for two located reasons: **specificity matching** (CjeI/CjePI
specify only 5 bases, cut every ~512 bp, and swamp the pool — tags jump
3.3× for two enzymes) and **IUPAC geometry** (`geometry_from` treats `Y` as
fully specified; a transition at `Y` preserves the site, so HaeIV/Hin4I
violate the `site_len`/`body_len` the likelihood assumes — the 11-enzyme
panel with HaeIV degrades on every metric at once). BsaXI is separately bad
(8-panel simulated MAE 0.071→0.174). A 15-enzyme panel did not finish one
pair in 10 minutes — a practical ceiling.

**(c) Tag composition vs GC** (ALGORITHM_MLE §4.8): Type IIB sites are
GC-biased (only FalI 33% and PsrI 43% site-GC lean AT; the rest 57–80%), so
the enzyme *composition* of the tag pool shifts with genome GC: FalI
supplies 78% of tags at GC 27.2% while BcgI alone supplies 56% at GC 60.1%;
BcgI swings 53× across the range (density spans 3.4×, 610–2,101 tags/Mb).
Because the likelihood pools all enzymes under one divergence and one
shape, every genome pair hands it a compositionally different sample — the
proximal cause of per-genome offsets like panel (a)'s.

**The BslFI episode** (V8 §3.14) is why this section exists. A brief CLI
default of `AloI,BslFI` (commit aae280c, reason undocumented) scored **MAE
3.08%** on the exact-truth ladder (−6.5 at 85%, −3.4 at 95%), vs 0.074%
for the 4-enzyme panel. Two stacked causes: (1) a registry geometry error —
`EnzymeConfig::bsl_fi()` declared `tag_length=21` while the digest table
cuts a **25 bp** window (6 flank + GGGAC + 14 downstream), shortchanging the
MLE body by 4 bp; fixing 21→25 moved the bias from −3.0 to −1.9 at 95%;
(2) the residual −1.9 is site turnover: GGGAC is severely underrepresented
in *E. coli* (1,334 sites vs ~4,500 expected), 5% divergence creates +31%
new sites (query 3,518 vs reference 2,679), and tags from created sites have
no homolog and score as misses — the loss model has a destruction term
(a^s) but no creation term. The bias magnitude therefore **depends on the
genome's motif representation**, not on a constant.

**Consequence:** the default is restored to **BcgI,AlfI,AloI,FalI**, and the
GTDB-R207 embedded calibration model was trained on this panel's feature
distribution. Modeling site turnover in the likelihood (a creation term, or
bidirectional runs separating destruction from creation) is an explicit
follow-up.

### 3.4 Mid-ANI against ANIm truth (F4) — secondary small-n check

![F4](../figures/report/fig4_midani_anim_validation.png)

*This is a secondary, small-n check (15 pairs in one narrow band); the main
independent-truth result is §3.5.*

Fifteen oral/gut pairs (*B. longum × B. breve*, *V. parvula × V. dispar*)
with ANIm (nucmer/dnadiff 1-to-1) as truth, range 87.6–90.2%
(`results/validation_mid_ani_anim/`). Important truth caveat: **ANIm
alignment coverage is only 46–72%** of these genomes (`anim_aligned_query`
45.0–72.0) — the truth itself sees barely half the genome. ANIm also shows
FastANI reading 1.5–2 points systematically low in this band (V8 §3.13).

Old run (2026-08-11, then-default 2-enzyme panel AloI,BslFI) vs new run
(`anim_4e`, current 4-enzyme panel), vs ANIm:

| Method | MAE old → new | bias old → new | r old → new |
|---|---|---|---|
| syn2bani uniform | 0.862 → **1.423** | +0.523 → +1.423 | 0.431 → **0.683** |
| syn2bani gamma | 10.290 → **4.482** | −10.290 → −4.414 | 0.394 → −0.543 |
| skani | 1.396 (unchanged) | −1.396 | 0.672 |
| FastANI | 1.864 (unchanged) | −1.864 | 0.521 |

Read this honestly: the 4-enzyme panel **improved gamma dramatically and
improved correlation, but uniform MAE got worse** (0.862→1.423, now fully
biased high) and gamma's correlation went negative. In this regime —
ANI ~88–90%, retention 0.32–0.53, a few hundred shared tags — the gamma
shape and mean are coupled at the identifiability boundary and gamma
overshoots low by 4–10 points (V8 §3.13); the LRT gate (2·ΔlnL > 3.841) is
too permissive to stop it.

The saving grace was the diagnostic: **all 15/15 pairs were flagged
INCONSISTENT in both runs** (hist−loss gap 6.5–10.3, far over threshold), so
a user filtering on the flag never saw these numbers. This is now fixed at
the estimator level (§5 item 1): the effect-size gate falls back to the
homogeneous fit on 12/15 pairs — gated MAE **0.959** vs gamma 4.482 — and
the recalibrated flag marks exactly those 12; the 3 pairs it keeps on gamma
are the ones where gamma was already right (errors 0.15–0.52).

set). The calibration is ridge regression
on Syn2bANI-internal features only (`s2b_ani`, `s2b_ani_uniform`, `s2b_af_q/r`,
`s2b_std_err`, `s2b_retention`, `s2b_n_anchors/chains/tags`), trained under
band-holdout cross-validation: each band is predicted by a model trained on
the other three bands only (`scripts/anim_main_table_4e.py`). The v5 row is
the same protocol on an enlarged training set (2,520 pairs: the 2,053
finite gated pairs plus 467 new 95–99.5% ANIm pairs; see the v4/v5
paragraphs below), so its "all" column is not directly comparable to the
v2 history row —
its gain is concentrated in the 95–99 band, where n went 72 → 539.

**Calibration v2 (current-binary features).** The model above was retrained
on the current-binary feature matrix (`results/anim_truth_2074_v8current.tsv`,
2,053 finite pairs; `scripts/calibration_v2.py`, full write-up
`results/panel_by_band/CALIBRATION_V2.md`). A feature-set comparison under
the same band-holdout CV: the base 9 features give MAE 0.988; an expanded
18-feature set (adding `anchor_adjacency`, `breakpoint_count`, `enzyme_spread`,
`enzyme_chi2`, `het_shape`, `ani_from_loss/hist`, block-anchor stats) gives
**MAE 0.963, winning every band**; a gradient-boosted model on the same
features scores 1.224 — nonlinearity buys nothing at n ≈ 2k, consistent
with the learning-curve plateau above. External validation: on the oral/gut
100 same-species pairs vs FastANI (re-run with the current binary,
`results/oral_gut_1225_v8current.tsv`) the calibrated Set-A model scores MAE
**0.460** (bias +0.152, r 0.995) vs raw 0.552, while **Set B degrades
out-of-distribution** (MAE 0.636, r 0.927 — its GTDB CV edge does not
transfer to near-clonal pairs); on the mid-ANI 15 pairs vs ANIm the
calibrated Set-B model scores MAE **1.229** (bias −0.845, Set A 1.343),
better than raw uniform (1.423) and raw gamma (4.482) — calibration also
fixes the gamma overshoot in exactly the band where gamma fails (§3.4).
Net recommendation: ship Set A — **shipped** as the embedded
`--calibrate` model (pure JSON swap of `models/gtdb_r207_linear_cal.json`;
feature order and scaling match `predict_from_result` exactly, all 62 lib
tests pass; **since superseded by v3, below**). Two behaviors of the shipped
calibration (true of v2 and v3 alike) are worth knowing. On
exact-truth uniform-rate simulations it slightly *under*estimates (e.g.
94.66 against truth 95.000): the model learned the real-data association
"high retention → overestimation", which is absent in uniform sims, so
`--calibrate` is tuned for real pairs and the raw estimate remains the
reference on clean simulated data. And it returns NaN by design on
`BELOW_DETECTION` pairs rather than extrapolating a confident number.
One training-choice caution: pairs were
**not** filtered by the consistency flag, because the flag is inverted on
GTDB — on the current matrix vs ANIm, `ok` pairs score MAE 4.11 (n = 832)
vs 1.97 for INCONSISTENT (n = 1,137) (§3.6). Since then the flag has been
recalibrated and the estimator gated (§5 item 1, §6): the raw estimator
underneath the calibration improves to MAE 2.819 (`ani_gated`, vs 2.881
gamma; per-pair oracle bound 2.788) on this matrix and to 0.959 from 4.482
on the mid-ANI set.

**Calibration v3 (gated estimator) — the shipped model.** The ridge was
retrained against `ani_gated` (`results/anim_truth_2074_gated.tsv`;
`scripts/calibration_v3.py`; CALIBRATION_V2.md §6) and shipped at Syn2bANI

ascertainment correction was derived and **failed twice** (overshoot to
−1.81; divergence to −30.8); it is not applied, and `simulate_mosaic.py`
should gate any future attempt (ALGORITHM_MLE §4.9).

The flag behaves badly here in a specific, understood way: on GTDB, `ok`
pairs score *worse* than INCONSISTENT ones (4.862 vs 2.476) — **inverting
the oral/gut ranking**. The check compares `ani_from_hist` and
`ani_from_loss` over the *same* chain-restricted tag set; it can detect the
two signals disagreeing, but not both being biased in the same direction by
a selected tag sample — and cleanly-chained pairs are exactly where that
selection is strongest (ALGORITHM_MLE §4.9). This is a real limitation of
the diagnostic as designed.

## 5. Statistical model choice: uniform vs gamma (and beyond)

**Assumptions.** The uniform estimator posits a single per-site substitution
rate; tag survival is then exponential in divergence, and the per-tag
mismatch count is Poisson. The gamma estimator lets regional rates vary as
r ~ Gamma(α, α) — a Yang-style discrete-rate idea in continuous form — which
turns the mismatch count negative-binomial; α → ∞ recovers the uniform model
as a boundary, so the two are nested (V8 §3.6; ALGORITHM_MLE §2.1). Two
guardrails are already in place, both learned from failures: a likelihood-
ratio gate (second parameter spent only when 2·ΔlnL > 3.841) and α clamped
to [0.1, 200].

**Evidence from our own data.** Real pairs are mosaics, and where retention
is high the gamma model is clearly better: on mosaic simulations with exact
truth, gamma MAE 1.71 vs uniform 2.98 (§4.9); on Enterobacteriaceae, gamma
0.094 vs uniform 0.707 vs skani (§3.7). But gamma has an **identifiability
boundary**: at mid-ANI with low retention (a few hundred shared tags), shape
and mean couple, the LRT gate is too permissive, and gamma overshoots low by
4–10 points while uniform stays stable (§3.4; V8 §3.13). All 15 such pairs
were caught by the INCONSISTENT flag — but that is a heuristic alarm, not
model selection.

**Conclusion.** The uniform/gamma choice must be a **function of divergence
and tag evidence, not a global switch** — and as of the gating work below it
now is: `ani_gated` chooses per pair, via the effect-size fallback of
roadmap item 1.

**Roadmap, ordered by cost:**

1. ~~**Formal nested-model gating.**~~ **IMPLEMENTED — and the formal
   machinery lost.** Prototyping on the 2,053-pair GTDB-ANIm matrix (with
   exact per-pair likelihoods re-fitted from dumped per-enzyme strata) showed
   the significance-based gates are all no better than the existing LRT
   support gate on GTDB: BIC (`lrt > ln n_tags`) scores MAE 2.913 vs 2.881
   for the plain gamma column, the chi-bar-square boundary threshold is
   identical to the current gate (2.881), and `|gamma − uniform| > k·SE`
   rules collapse toward always-uniform (3.46+). What works is an
   **effect-size gate**: fall back to the homogeneous fit when
   `|ani_from_loss − ani_from_hist| > 5` ANI points. Chosen on GTDB-ANIm
   (flat optimum over 4.5–6 points; MAE 2.819 vs the 2.788 per-pair oracle
   bound), it fires on 12/15 mid-ANI pairs (MAE 4.482 → **0.959** — the
   §3.4 overshoot is fixed at the estimator level), 0/100 oral/gut
   same-species pairs, 0/12 uniform-rate sims, and 0/9 mosaic sims, where
   the gamma advantage (1.711 vs 2.975) is fully preserved. Shipped as new
   output columns `ani_gated` (the recommended raw estimate) and `gate`
   (`gamma`/`uniform`/`uniform_fallback`/`none`); `ani` and `ani_uniform`
   are unchanged. Full evidence: `results/gating_flag/RULES.md`.
2. **Discrete gamma (4 categories).** More stable than continuous α when
   tag counts are sparse; cheap to fit by the same MLE path.
3. ~~**Exploit chain spatial information.**~~ **DONE — NEGATIVE RESULT.**
   A full Phase-1 prototype (Python, gated on 19 exact-truth mosaic sims
   including new 1/5/20 kb block-size replicates, then evaluated on
   GTDB-ANIm and both negative controls) establishes that the bias has two
   additive terms, and only the smaller one is fixable. **(a) Distribution-
   family term:** even with infinite in-chain data the parametric fits
   misplace tail mass (asymptotic MAE: gamma 2.25, free two-component 2.20,
   capped grid NPMLE 1.25); a capped NPMLE fixes this term on the mosaic
   sims (2.64 → **1.47**, near the 1.25 floor). **(b) Coverage term:** the
   unchained fraction's divergence is *not identifiable* from tag data at
   this density — the out-of-chain anchor residual is ≈ 0 within
   multi-match noise whether the unchained mass is saturated-divergent or
   accessory, and an oracle knowing the exact chained-sample identity still
   errs by MAE 1.36 against whole-genome truth. On GTDB the unchained mass
   is accessory-dominated (ANIm excludes accessory too): the implied
   unchained identity is band-determined, not pair-determined, and within
   every band the error tracks AF at r ≈ −0.75 while truth is flat in AF —
   exactly the association the ridge calibration already captures. No
   candidate beats the gated baseline (2.819) while holding all simulation
   gates: the capped NPMLE fails the uniform-sim gate ungated (0.216 > 0.1)
   and the mid-ANI control gated (1.359 vs 0.959), and its LRT-gated form
   passes sims but *loses* on GTDB (2.867). Per-block exports
   (`ani --blocks-out`) were evaluated and rejected on paper: they sharpen
   only the in-chain family term (≤ 0.6 GTDB MAE), not the coverage term
   where the bias lives. The raw estimator is therefore at its
   identifiability floor at 4-enzyme tag density, and calibration is the
   correct correction layer. Full derivation, candidates, and per-dataset
   tables: `results/spatial_model/MODELS.md`.
4. ~~**Model averaging** (BIC weights)~~ **EVALUATED — REJECTED.** The
   item-3 analysis included averaging (gamma/NPMLE 50/50 and LRT-gated
   switching): the average is the best GTDB variant (2.634 vs 2.819) but
   fails the uniform-sim gate (0.107) and interpolates the mid-ANI
   degradation (~1.2 vs 0.959). Discontinuous switching is not the
   bottleneck; identifiability is.

**Statistical honesty:** any new model must be validated on mosaic
simulations with known truth (`simulate_mosaic.py` runs in about a minute)
before being trusted on GTDB or against ANIm — the tilted-Gamma correction
(§3.6) is the standing cautionary example of skipping that gate.

## 6. Limitations and next steps

- ~~**Gamma fallback gating is unimplemented.**~~ **DONE** — see §5 item 1:
  the effect-size gate (`|ani_from_loss − ani_from_hist| > 5` points ⇒
  homogeneous fit) ships as the `ani_gated` column and fixes the mid-ANI
  overshoot (4.482 → 0.959) without touching the regimes where gamma wins.
- ~~**INCONSISTENT flag needs recalibration per divergence band**~~
  **DONE.** The flag is recalibrated, not per band but by construction:
  `INCONSISTENT` now means the gate fell back (model disagreement) **or**
  the chains carry more than 0.5 rearrangement breakpoints per anchor — a
  structural statistic that does not share the chain-restricted likelihood
  denominator, the fix this bullet asked for. `BELOW_DETECTION`
  (retention < 0.20) is unchanged and takes precedence. The new ranking
  does not invert on any validation set (kept vs flagged MAE: GTDB-ANIm
  2.415 vs 4.153; oral/gut 0.514 vs 4.269; mid-ANI 0.343 vs 1.113), where
  the old flag ranked GTDB backwards (§3.6). The honest residual: the old
  flag's near-clonal sensitivity (oral/gut kept-set MAE 0.293) is not fully
  recovered (new kept 0.514) — that sensitivity came from the
  significance-scaled gap, which inverts on GTDB at every threshold — and
  the mosaic-sim bias is systematic rather than per-pair detectable, so
  those sims now read `ok`. Flagged pairs are now reliably worse; not all
  bad pairs are flagged.
- ~~**Fragmentation realism gap.**~~ **DONE** (§2.4). The mechanism was not
  chain acceptance per se but miss-count selection on unchainable contigs;
  the fix is the short-contig rescue pass, which re-admits those contigs
  under the intact-genome counting rule. Sakai N50 5 kb drift +0.654 →
  +0.200 (beats skani/FastANI on the same file), worst real-draft bias
  +0.91 → +0.36, complete genomes bit-identical. The residual +0.20 at
  N50 5 kb is contigs with 0–1 placeable anchors (~1.3 Mb), which carry no
  positional evidence; rescuing them would mean guessing homology. The
  simulation/realism gap itself stands as a methodological lesson — the
  fix was validated on real drafts, not sims.
- **Calibration demonstrated externally; v5 deployed.** The raw GTDB
  overestimation (bias +1.86 vs ANIm post-rescue) is removed by a band-holdout ridge
  calibration on internal features (§3.5). The deployed model is **v5**
  (Syn2bANI `fe0f36c`): the 9-feature ridge (primary feature `ani_gated`)
  retrained on 2,520 pairs re-run with the post-rescue binary — overall CV
  MAE **0.731**, 95–99 band **0.712**, bias +0.05, r 0.963, seed spread
  ≤ 0.0015. Tradeoffs vs v4, disclosed: 85–90 band +0.034, oral/gut
  external 0.497 (v4: 0.463), mid-ANI external 0.806 (v4: 0.794, well
  within noise at n = 15); both externals remain far better than raw
  (0.552, 0.959).
  v3 (shipped at Syn2bANI `15da386`) and v4 remain as fallbacks; v5 ships as a
  `models/gtdb_r207_linear_cal.json` swap. Remaining caveats: the mid-ANI
  set is not gate-independent, and on exact-truth uniform sims the
  calibrated value underestimates slightly — the raw estimate remains the
  reference there. A mechanistic fix (spatial rate model, roadmap item
  3 in §5) was attempted and produced a rigorous negative result: the raw
  estimator is at its identifiability floor at the current tag density —
  the fixable in-chain family term is worth ≤ 0.6 GTDB MAE, and the
  dominant coverage term is not observable in tag statistics — so
  calibration is the right correction layer for this bias. Forward
  pointer: revisit the capped-NPMLE in-chain fit (mosaic 2.64 → 1.47; fits
  already computed in `results/spatial_model/gtdb_spatial.tsv`) if tag
  density rises once the IUPAC geometry fix enables a wider enzyme panel —
  deeper retention makes the divergent tail directly observable in-chain.
- **Small-scale efficiency benchmark.** n ≤ 22, all-vs-all; skani's n = 22
  time covers only 302/484 reported pairs; database-scale `search`/`triangle`
  now measured at 5,000-genome scale post-rewrite (§4 end).
- **ANIm truth covers only ~46–72% of genome length at divergent bands**
  (§3.4) — the best available truth there is itself a partial-genome
  measurement, so the ~0.9 MAE of the calibrated and reference tools may
  approach the truth-noise floor; the Enterobacteriaceae and draft
  validations have no ANIm cross-check yet.
- **Site turnover not modeled in the likelihood.** Mutation creates new
  recognition sites (+31% for BslFI at 5% divergence); the loss model has a
  destruction term only. This is the standing explanation for per-enzyme
  bias (F3a) and part of the BslFI failure (§3.3).
- ~~**IUPAC degenerate sites break the geometry**~~ **DONE** (code repo
  f054dbb; `results/iupac_fix/`): digestion itself was also permissive —
  the HaeIV/Hin4I/BaeI patterns dropped the trailing fixed anchor bases —
  and both are fixed. Geometry now carries `{exact_site, d2, d3}` parsed
  from the IUPAC anchors, with the exact convolution (homogeneous) and
  NB-plus-survival-factor (gamma) likelihoods; the fully-specific default
  panel takes the bit-identical old path. HaeIV+Hin4I simindel MAE 0.273 →
  0.242. This unblocks the wide-panel revisit and the capped-NPMLE pointer
  above.
- **Single-species simulation base.** All exact-truth families except the
  GC sweep evolve *E. coli* K-12; accessory blocks are shuffles (no real
  gene structure); no true MAGs (binning error, cross-species contamination)
  in any validation set (V8 §4).
