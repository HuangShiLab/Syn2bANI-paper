== syn2bani ani --help ==
Chain-restricted ANI by maximum likelihood (no calibration model)

Usage: syn2bani ani [OPTIONS] [QUERY]...

Arguments:
  [QUERY]...  Positional form: every path but the last is a query, the last is the reference. Two greedy lists cannot be split any other way, so use --ql/--rl when you need more than one reference

Options:
      --ql <FILE>
          File listing query paths, one per line
      --rl <FILE>
          File listing reference paths, one per line
  -e, --enzymes <ENZYMES>
          Comma-separated enzyme panel (tags must be <= 32 bp) [default: BcgI,AlfI,AloI,FalI]
      --mismatch-tolerance <MISMATCH_TOLERANCE>
          Mismatch budget per tag; 0 = exact match only [default: 2]
      --min-chain-anchors <MIN_CHAIN_ANCHORS>
          Minimum anchors for a trusted chain [default: 4]
      --max-gap <MAX_GAP>
          Max bp between chained anchors [default: 50000]
  -t, --threads <THREADS>
          Number of threads (0 = auto) [default: 0]
  -p, --parallel
          Enable parallel processing
      --verbose
          Also report the two partial estimators and chain diagnostics
      --strata-out <FILE>
          Dump per-enzyme sufficient statistics for `panel` re-scoring
      --calibrate
          Apply embedded linear calibration model; adds an ani_cal column
      --calibrate-model <FILE>
          Path to a custom calibration model JSON (requires --calibrate)
  -o, --output <OUTPUT>
          
  -h, --help
          Print help
