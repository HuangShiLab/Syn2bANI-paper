# GTDB R207 metadata

This directory is used by `analysis/analyze_gtdb_quality_vs_mae.py`.

Download the GTDB R207 metadata TSV files from:

- Bacteria: https://data.gtdb.ecogenomic.org/releases/release207/207.0/bac120_metadata_r207.tsv
- Archaea: https://data.gtdb.ecogenomic.org/releases/release207/207.0/ar53_metadata_r207.tsv

Place the downloaded `.tsv` files directly in this directory. The compressed
`.tar.gz` archives are not required.
