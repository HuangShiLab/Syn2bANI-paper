# Figure captions — syn2bani methods/validation report figures

Generated by `analysis/plot_report_figures.py` (pure pandas/matplotlib; no heavy
compute). Each figure is provided as PNG (300 dpi) and PDF. Tool colors follow
Okabe–Ito: syn2bani uniform `#0072B2` (blue), syn2bani gamma `#D55E00`
(vermillion), skani `#009E73` (green), FastANI `#CC79A7` (reddish purple),
truth/identity references in black/grey. Errors are in ANI percentage points.

## Figure 1 — Simulation-ladder accuracy (`fig1_simulation_ladder`)

Twelve query genomes simulated from one reference at true ANI 85.0 → 99.9%
(with indels; ~98.9% of sequence kept), estimated with `syn2bani ani --verbose`
(4-enzyme panel). Data: `Syn2bANI/prototype/simindel_results_4e.tsv`, truth from
`Syn2bANI/prototype/simindel/manifest.tsv`. N = 12 pairs. (a) Estimated vs true
ANI for the gamma and uniform divergence estimators; dashed line is identity.
(b) Signed error (est − truth) vs true ANI; per-tool MAE annotated in (a).
Comparators: skani 0.1.0 (`skani dist --ql/--rl -t 16`) and FastANI 1.33
(`--ql/--rl -t 16`) on the same 12 query genomes vs `ref.fasta`
(`Syn2bANI/prototype/simindel_cross_tool_4e.tsv`); both tools reported all 12
pairs (no min-AF drops). Headline: syn2bani MAE = 0.073 ANI points for both
estimators (worst single error +0.21 at true ANI 88%), vs skani MAE = 0.377
(bias −0.377) and FastANI MAE = 0.742 (bias −0.742) — both comparators
systematically underestimate, increasingly so toward the low-ANI end
(FastANI −2.05 at true ANI 85%). Caveat: in this run the `ani` (gamma) and
`ani_uniform` columns are numerically identical for all 12 rows, so the two
series overlap exactly — the estimators are not distinguishable on this ladder.
The 85% level is flagged `BELOW_DETECTION` by syn2bani (shown here for
completeness).

## Figure 2 — Robustness (`fig2_robustness`)

(a) *Indel sweep.* True ANI fixed at 95.000, indel rate 0–4 per 100 kb.
Data: `simindel_sweep_results_4e.tsv` + `simindel_sweep/manifest.tsv`. N = 5.
Error grows mildly with indel load, worst +0.18 at 4/100 kb.

(b) *Fragmentation.* Reference ANI 95.000 query split into 20–200 contigs;
~half of the contigs are reverse-complemented and the order shuffled
(manifest `flipped=True`). Data: `simfrag_results_4e.tsv` + `simfrag/manifest.tsv`.
N = 4. Error rises with contig count (worst +0.18 at 200 contigs) but stays
below 0.2 ANI points.

(c) *GC sweep.* MAE against exact simulation truth for five genomes spanning GC
27–72%, hardcoded from `Syn2bANI/ALGORITHM_MLE.md` §4.8. Headline: MAE is **not
monotone in GC** — the worst genome is *B. longum* at GC 60.1% (MAE 0.356,
essentially pure bias), not the composition extremes; the balanced 5-enzyme
panel improves 4 of 5 genomes (mean MAE 0.179 → 0.153).

(d) *Accessory fraction.* True ANI fixed at 95.000 with 0–50% accessory
content; hardcoded from `V8_MLE_VALIDATION.md` §3.2. N = 6. The ANI estimate
stays flat (errors +0.04…+0.25, not monotone in accessory fraction; MAE 0.114)
while `af_query` tracks 1 − F to within 0.004 — the two signals are decoupled.
Caveat: a residual uniform bias of ~+0.1 ANI points of unknown origin remains
(documented in §3.2/§3.3 of the validation note).

## Figure 3 — Enzyme-panel optimization (`fig3_enzyme_panel`)

(a) *Per-enzyme bias.* Ten replicate genomes at exactly 95% ANI with uniform
per-site divergence, so no enzyme has a legitimate reason to disagree;
hardcoded from `V8_MLE_VALIDATION.md` §3.12. Bars: bias of the per-enzyme ANI
estimate; error bars: SD across the 10 replicates; annotations: significance.
AlfI +0.273 (9.0σ) and FalI −0.586 (8.8σ) disagree significantly despite fully
specific recognition sites; BcgI (+0.095, 2.9σ) and AloI (+0.011, 0.2σ) do not.
This was a largely negative result: site-length bookkeeping, IUPAC degeneracy,
and tag overlap were all excluded as causes.

(b) *Panel-size trade-off.* Hardcoded from `ALGORITHM_MLE.md` §4.7.1. X: tags
in chains on a real genome pair (log scale); Y: MAE on real genomes (vs skani,
vermillion) and on simulated data with known truth (blue). The default
4-enzyme panel has the best real-genome agreement (MAE 0.094); larger panels
help AF and simulated precision but degrade real-genome MAE — worst for the
11-enzyme panel containing the degenerate-site enzyme HaeIV (0.670) and for the
8-enzyme panel with the low-specificity CjeI/CjePI (0.290).

(c) *Tag composition vs GC.* Per-enzyme share of tags per Mb for five genomes
spanning GC 27–72%; hardcoded from `ALGORITHM_MLE.md` §4.8. At GC 27.2% FalI
supplies 78% of all tags while BcgI+AlfI supply 8.7%; at GC 60.1% BcgI alone
supplies 56%. Because the likelihood pools all enzymes under one divergence,
every genome pair hands it a compositionally different sample.

## Figure 4 — Mid-ANI validation against ANIm (`fig4_midani_anim_validation`)

Fifteen genome pairs from three species pairs (*Bifidobacterium longum ×
B. breve*, *Veillonella parvula × V. dispar*) with ANIm (whole-genome
alignment) as truth, ANIm range 87.6–90.2%. Data:
`results/validation_mid_ani_anim/anim_4e/anim_midani_evaluation.tsv`; metrics
from `anim_midani_metrics.tsv`. N = 15. (a) Estimated vs ANIm truth for
syn2bani gamma, syn2bani uniform, skani, and FastANI; dashed line is identity.
(b) Per-pair signed error (est − truth), pairs sorted by ANIm truth; grey
connectors link the four methods within a pair. Metrics (MAE / bias / r vs
ANIm): syn2bani gamma 4.48 / −4.41 / −0.54; syn2bani uniform 1.42 / +1.42 /
0.68; skani 1.40 / −1.40 / 0.67; FastANI 1.86 / −1.86 / 0.52. Headline: in
this hard mid-ANI regime every method is off by 1.4–1.9 ANI points and the raw
syn2bani gamma estimate fails badly (−4.4 bias) — but **all 15/15 pairs are
flagged INCONSISTENT** by syn2bani's per-enzyme diagnostic (black-edged
syn2bani markers), so downstream users would never see the unvetted numbers.
The flag, not the point estimate, is the result in this regime.

## Figure 5 — GTDB R207 large-scale benchmark vs FastANI (`fig5_gtdb_r207_benchmark`)

45,000 GTDB R207 genome pairs run through syn2bani, skani, and FastANI. Data:
`results/matrix_gtdb_r207_100k_v8_final.tsv`. FastANI reports an ANI for only
672 pairs (all in the `mid_high` stratum, FastANI 81.6–97.7%); the comparison
is restricted to those. syn2bani flags among them: 215 ok, 405 INCONSISTENT,
52 BELOW_DETECTION (BELOW_DETECTION pairs have no syn2bani ANI estimate, so
syn2bani metrics use n = 620; skani n = 672). (a) syn2bani uniform vs FastANI:
log-count hexbin (grey) with per-pair overlay colored by syn2bani flag. (b, c)
MAE and bias vs FastANI, binned by FastANI ANI. Headline (also in
`gtdb_metrics_summary.tsv`): skani agrees with FastANI well (MAE 0.61, bias
+0.30, r 0.98); syn2bani uniform shows MAE 4.24 with bias **+4.24** (r 0.81)
and syn2bani gamma MAE 3.30, bias **+3.02** (r 0.73). The strong positive bias
is not hidden: it is concentrated in the lowest FastANI bins (panel c) and
68% of these pairs are flagged INCONSISTENT/BELOW_DETECTION by syn2bani itself
— i.e. the tool marks most of its own bad estimates. Restricting to `ok` pairs
is the intended operating mode; the unfiltered numbers are shown here for
honesty.

## Figure 6 — Computational efficiency (`fig6_efficiency`)

All-vs-all ANI for nested genome subsets (n = 2, 5, 10, 15, 22 genomes; n²
pairs including self pairs; 14 complete Enterobacteriaceae chromosomes plus 8
real draft E. coli assemblies at n = 22), 3 repetitions per configuration;
points are medians, error bars the min–max range. Machine: Mac Studio, Apple
M4 Max 16 cores, 128 GB RAM, macOS 26.5.1. Tool versions: syn2bani 0.1.0
(Syn2bANI main @ 69ce9f4, default 4-enzyme panel), skani 0.1.0, FastANI 1.33
(defaults k = 16, fragLen = 3000). Threads: syn2bani `-t 0` (all 16 cores),
skani and FastANI `-t 16`. Timing via `/usr/bin/time -l`. Data:
`results/efficiency_v8/runtime_scaling.tsv` and `sketch_benchmark.tsv`;
full configuration in `results/efficiency_v8/MACHINE.md`.

(a) Wall time vs number of pairs (log–log). At n = 22 (484 pairs): skani dist
0.15 s, syn2bani from sketches 2.79 s, syn2bani from FASTA 3.73 s, FastANI
17.7 s. Caveats: **skani dist reported only 302/484 pairs at n = 22 because of
its min-AF filter, so its times are not strictly like-for-like**, and the skani
dist time excludes its (small) sketch step; the syn2bani sketch-reuse time
likewise excludes the one-time sketch cost (0.50 s at n = 22), which pays for
itself by the second `ani` run against the same sketch set.

(b) Peak RSS vs number of pairs (log y). Sketch reuse drops syn2bani's peak
memory from 310 MB to 58 MB at n = 22 (skani dist 185 MB, FastANI 912 MB).

(c) Sketch store total size vs number of genomes (log y). syn2bani's `.s2ba`
store is ~5× smaller than skani's database: 4,020 vs 21,592 KB at n = 22
(per-genome `.s2ba` files vs per-genome `.sketch` files plus `markers.bin`).

## Figure 7 — ANIm-truth benchmark by ANI band (`fig7_anim_by_band`)

2,074 GTDB-R207 genome pairs with dnadiff (ANIm) truth, binned into four ANI
bands (80–85, 85–90, 90–95, 95–99%). Methods: syn2bani current default
4-enzyme panel (BcgI,AlfI,AloI,FalI) raw gamma estimate; the same panel after
ridge-regression calibration with band-holdout cross-validation (train on 3
bands, test on the held-out band; Syn2bANI-internal features only); the old
11-enzyme panel (raw); and skani. FastANI covers only a 363-pair subset and is
shown faint/dashed. The 105 BELOW_DETECTION pairs (no 4e point estimate) are
excluded from the 4e rows, so 4e n = 1,969 vs 2,074 for 11e/skani. Data:
`results/panel_by_band/anim_main_table.tsv` and `ridge_cv_preds_4e.tsv`;
methods in `results/panel_by_band/ANIM_MAIN_TABLE.md`.

(a) MAE vs ANI band. Raw 4e gamma degrades sharply toward lower ANI
(MAE 3.69 at 80–85% vs 1.16 at 95–99%); ridge calibration flattens this to
0.85–1.38 across bands, reaching skani-level overall accuracy (MAE 0.906 vs
skani 0.906) without using any external-tool feature. (b) Signed bias vs band.
Raw 4e gamma overestimates by +2.6 points overall (up to +3.3 at 80–85%);
ridge-CV bias stays within ±1.2 except the small 95–99% band (n = 72,
−1.19). skani and FastANI slightly underestimate (bias −0.65 / −0.98
overall). (c) Ridge-CV estimates vs ANIm truth for the 1,969 finite 4e pairs,
colored by band (identity line dashed). Overall MAE 0.906, r = 0.913; the
residual spread is largest in the 80–85% band, where shared-tag signal is
weakest.
